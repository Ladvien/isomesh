| | | *Distance is measured geometrically, not from `\|f(p)\|`, and this is one unconditional path rather than two.* `\|f\|` is a distance only where `\|∇f\| = 1`, which is false for `gyroid` and `fbm_terrain`, so branching on `is_exact_distance()` would put two execution paths in the harness.

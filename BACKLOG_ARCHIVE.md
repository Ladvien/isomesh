| | | *Distance is measured geometrically, not from `\|f(p)\|`, and this is one unconditional path rather than two.* `\|f\|` is a distance only where `\|∇f\| = 1`, which is false for `gyroid` and `fbm_terrain`, so branching on `is_exact_distance()` would put two execution paths in the harness. The obvious branch-free repair `\|f\|/\|∇f\|` is rejected by the field module's own argument — dividing by `\|∇f\|` "introduces a second failure mode wherever `\|∇g\| → 0`" — and is only first order. What ships is the **gradient-flow chord**: Newton-project the sample onto the zero set and measure how far it moved. Exact for the five true distance fields (the first step lands on the surface and its length *is* `\|f\|`), convergent on the other two, and it follows `fields/mod.rs`'s standing instruction that "an accuracy harness should measure against geometry rather than against `\|sample\|`".

fBm terrain intersected with a thickened gyroid, so the camera flies through the rock — under arches, into tunnels, out the far side of a wall — which a heightfield cannot represent at all. This is the demo that needs IsomeshPlugin's streaming, and until ✗44 that plugin panicked on its first chunk in any browser.

It runs at its committed defaults here. The example reads ISOMESH_* environment variables to override the stream radius and the frame budget, and a browser has no environment — so every one of them takes the documented default rather than something a URL chose.

One thing to expect if you open the console on this one: streaming churns meshes continuously, and Bevy 0.19's bevy_render slab allocator logs "Use-after-free: attempted to copy element data for an unallocated key" once per affected mesh under the WebGL2 backend — 3,186 times in a 45-second measured run. The demo streams and renders correctly through all of it (411 chunks resident, 229,580 triangles). It is upstream of this repository and it is not suppressed here, because a filter that hides a renderer's errors would also hide the next real one.
